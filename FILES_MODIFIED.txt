DEPLOYMENT WORKFLOW

   $ npm run build
   → Generates manifest, shows filtering output
   → Check: Are old posts excluded? Are recent posts included?

   $ npm run dev
   → Start dev server on http://localhost:3000/navonmesh/
   → Check: Are articles sorted by category?
   → Check: Navigate dates in archive view
   → Check: Click index to verify sorting

    $ npm run deploy

    → Pushes to gh-pages
    → Old posts excluded automatically
